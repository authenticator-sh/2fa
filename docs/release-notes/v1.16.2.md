## Move to phone

Settings → Backup & Restore → **Move to phone** shows your accounts as a
series of QR codes that an authenticator on a phone scans one after another.

- **The format is the one Google Authenticator exports**, so our iPhone app
  reads it, and so does any other app that imports from Google Authenticator.
  Nothing is uploaded: the codes are drawn in the extension and go from the
  screen to the phone's camera.
- **You choose which accounts go.** An account whose settings the shared
  format cannot carry (Steam Guard, a period other than 30 seconds, a code
  length other than 6 or 8) gets a code of its
  own in the standard `otpauth://` form, so it arrives unchanged.
- **Nothing is removed here.** The last screen says how many accounts the
  phone should now show; they stay in the extension too.
- **The QR codes are your keys.** Anyone who sees them gets a copy of the
  accounts. The screen says so before it shows them: not during a call, not
  during a screen share.
- The first screen has a QR code for the iPhone and iPad app. The app is in
  App Review as this release goes out; until it is approved the code opens a
  page that says so.

## Smaller things

- **Settings → Pro shows your license key in full** on the install that holds
  it; a click copies it, for the other browser or the Mac app.
- A right-click menu with a long list of groups no longer closes as soon as
  the list is scrolled.

## Fixes

- With password protection on, every read of the vault key signalled the
  other open windows of the extension, which read the key and signalled again:
  a loop that kept the extension busy, worst with auto-lock set to **Every
  time**. The signal now goes out only when the vault opens or closes.
