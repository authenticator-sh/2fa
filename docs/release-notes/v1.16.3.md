## Traditional Chinese

- **繁體中文 is the 21st interface language.** It is in Settings → Language,
  and a browser set to Traditional Chinese (Taiwan, Hong Kong, Macau, or
  `zh-Hant`) opens in it without being asked. Until now those browsers got
  Simplified Chinese, and the list had nothing else to pick. The existing
  Chinese entry is now labelled 简体中文.
- Texts that come from our server (the Pro screen, announcements) are still
  written in Simplified Chinese for now, and help links open the Simplified
  pages of the site.

## Smaller things

- **Accounts can be dragged into a new order in the compact list** as well,
  not only in the normal one. As before, sorting has to be set to Manual.
- **Microsoft's own setup QR code gets an answer that helps.** Microsoft's
  2FA page first shows a code that only Microsoft Authenticator can read. The
  extension used to say "this isn't an authenticator setup code"; it now says
  to click **I want to use a different authenticator app** on that page and
  scan the code shown after it. The camera scanner stops on such a code and
  says the same, instead of scanning on in silence.

## What is sent to our server

- When adding an account is refused, the report that says which refusal it was
  can now carry one more word, from a fixed list: what kind of QR code it was
  when it was not a 2FA one (`microsoft`, `web`, `app`, `text`), or what was
  wrong with a typed key (`hex`, `digits`, `link`, `symbols` and the like).
  Never the code, the key, or any part of either.
